아니마룬 개인정보 처리방침

시행일 2026년 10월 10일

1. 모으는 정보

  • 게임 진행 — 정령·장비·재화·스테이지 기록 같은 세이브. 기본은 이 기기에만 저장됨
  • 구글 계정 연동 시 — 구글이 주는 계정 번호(UID). 이메일 주소는 설정 화면에 보여 주기만 하고 서버에 따로 저장하지 않음
  • 친구·레이드·결투 — 닉네임, 친구 코드, 대표 정령, 계정 레벨, 접속 표시
  • 문의함 — 직접 쓴 문의 내용과 보낸 시각
  • 휴대폰 알림을 켠 경우 — 알림을 받을 기기 주소(브라우저가 만드는 구독 정보)와 알림 종류별 켜고 끈 설정
  • 기기 구분 번호 — 한 계정을 여러 기기에서 동시에 쓰는 것을 막으려고 기기마다 만드는 임의의 번호

이름·전화번호·주소·결제 정보는 모으지 않음. 광고·분석 도구도 쓰지 않음.

2. 쓰는 곳

  • 기기를 바꿔도 진행을 이어 가게 하는 계정 저장
  • 친구 찾기, 함께 하는 레이드·결투, 우편 보내기
  • 문의에 답하기
  • 화로·파견 완료, 우편 도착 같은 휴대폰 알림 보내기

위 목적 말고는 쓰지 않고, 다른 사람이나 회사에 팔거나 넘기지 않음.

3. 저장하는 곳

  • Google Firebase (로그인·데이터베이스) — 계정 번호, 세이브, 친구·레이드·우편·문의, 알림 구독 정보
  • Cloudflare Workers (알림 서버) — Firebase에 저장된 알림 구독 정보로 알림만 보냄. 따로 저장하지 않음
  • GitHub Pages — 게임 파일을 내려 주는 곳. 접속 기록은 GitHub 정책을 따름
  • 이 기기의 브라우저 저장소 — 세이브, 설정, 덮어쓰기 전 진행(최근 3개)

4. 보관 기간과 지우기

  • 서버의 정보는 계정을 지워 달라고 요청할 때까지 보관함
  • 지우고 싶으면 게임 안 문의함으로 요청 — 계정 번호에 연결된 세이브·친구 정보·문의·알림 구독을 지움
  • 이 기기에 저장된 것은 설정의 「게임 초기화」나 브라우저 사이트 데이터 삭제로 바로 지울 수 있음
  • 휴대폰 알림은 설정 → 휴대폰 알림에서 언제든 끌 수 있고, 끄면 그 기기의 구독 정보를 지움

5. 어린이

만 14세 미만이라면 보호자 동의를 받고 구글 계정을 연동해 줘.

6. 바뀔 때

이 방침이 바뀌면 이 페이지와 게임 안 패치 노트로 알림.

7. 문의
