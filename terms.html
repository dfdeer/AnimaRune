아니마룬 이용약관

시행일 2026년 10월 10일

1. 게임

아니마룬은 개인 개발자 dfdeer가 만드는 무료 게임. 설치 없이 브라우저에서 하거나 홈 화면에 추가해서 할 수 있음.

게임을 하면 이 약관과 개인정보 처리방침에 동의한 것으로 봄.

2. 계정과 진행

  • 진행은 기본으로 이 기기에 저장되고, 구글 계정을 연동하면 서버에도 저장됨
  • 연동하지 않은 진행은 브라우저 데이터를 지우거나 기기를 바꾸면 사라질 수 있음 — 설정의 「세이브 내보내기」로 따로 보관 가능
  • 한 계정을 여러 기기에서 동시에 쓰면 나중에 접속한 기기만 저장됨

3. 게임 안 재화와 아이템

  • 정수·강화석·별빛 조각·소환권 같은 재화와 정령·장비는 게임을 하며 얻는 것이고, 현금으로 살 수 없음
  • 재화·아이템은 게임 안에서만 쓰이고 현금으로 바꾸거나 다른 사람에게 팔 수 없음
  • 소환에서 나오는 등급별 확률은 게임 안 소환 화면에서 볼 수 있음
  • 업데이트로 수치·확률·보상이 바뀔 수 있고, 바뀐 내용은 패치 노트로 알림

4. 개발 응원(후원)

  • 설정의 「개발 응원하기」는 보상이 없는 자발적인 응원 — 게임 안 혜택이 생기지 않음
  • 잘못 보낸 경우 게임 안 문의함이나 이메일로 알려 주면 확인해서 처리함

5. 하면 안 되는 것

  • 게임 코드·서버를 고쳐서 재화·기록을 부풀리거나 다른 사람 진행을 건드리는 것
  • 닉네임·문의에 욕설, 남을 괴롭히는 말, 개인정보를 쓰는 것
  • 서버에 일부러 부담을 주는 것

위 행동이 확인되면 진행을 되돌리거나 친구·레이드 같은 함께 하는 기능을 막을 수 있음.

6. 서비스 변경과 중단

  • 개인이 운영하는 게임이라 기능·콘텐츠가 바뀌거나, 미리 알린 뒤 서비스를 끝낼 수 있음
  • 서버 점검·장애로 잠시 계정 저장·친구·레이드가 안 될 수 있음
  • 무료 게임이라 진행 손실 등에 금전 보상은 하지 않음. 버그로 잃은 재화는 확인되면 우편으로 돌려줄 수 있음

7. 저작권

게임 그림·글·음악·코드의 권리는 아니마룬 개발자에게 있음. 무단으로 복제·배포하지 않기.
