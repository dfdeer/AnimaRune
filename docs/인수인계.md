## 5. 개발 도구
- **스크롤 진단 패널:** 왼쪽 위 '아니마룬' 제목을 3초 안에 5번 탭 → 스크롤 값·터치 대상 표시 (실기기 터치 문제 확인용 — 헤드리스 크롬으로는 재현 안 되는 경우가 있음)

- 개발 응원 버튼 `DONATE_URL`(카카오페이 송금코드, 휴대폰에서만, 이 창만 존댓말) — 계좌번호가 드러나는 링크는 넣지 않기
