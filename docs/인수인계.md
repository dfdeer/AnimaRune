## 5. 알아둘 코드 위치
- **전투**
  - 흐름: `performAction` → `makeActCtx`(C.hit/heal/shield/neg/burn/poison…)
  - 핵심 함수: `dealDamage`, `killUnit`, `settleQueue`
- **스킬 모음**
  - 정령 스킬: `LINE_KITS`
  - 레이드 보스: `RAID_BOSS_KITS` (`rboss_<id>`)
  - 챕터·월드 보스: `BOSS_UNIT_KITS` (`cboss_<gimmick>` · `ward` · `lavaAdd` · `wboss_<phase>`), `setBossKit()`로 붙임
- **보스 만들기**
  - 챕터 보스는 `buildBossWaveFight` 한 곳에서 만듦. 탐험·출정(`expBossEnemies`)·월드보스(`buildWorldBossFight`)가 모두 이 함수를 씀.
- **히든 업적**
  - 판정 함수: `hidMark` / `hidHas`
  - 승리할 때 공통 훅: `hidOnWin`
  - 체력 손실 기록: `hidHurt`
- **레이드**
  - 방 입장: `raidJoinRoom`
  - 잠금 판정: `raidBossUnlocked`
