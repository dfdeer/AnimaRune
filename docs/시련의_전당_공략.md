# 시련의 전당 공략

- 기준: v4.6.0 코드 (2026-10-03 다시 확인). 수순은 게임 엔진으로 직접 찾아서 **같은 순서로 다시 두면 이기는 것까지 확인**한 것
- 시련은 치명타·확률이 없어서 같은 순서로 하면 결과도 항상 같음 (적 행동도 매번 같음)
- 여기 적힌 건 해법 중 하나 — 다른 순서로도 깰 수 있음 (시련마다 찾은 서로 다른 해법 수 표기)
- "우리 편이 쓰러진 채로 남으면 실패" 시련은 부활(펜리르·스콜 자기 부활, 광명의 아군 부활)로 다시 일어나면 괜찮음
- 표는 내가 누를 행동만 적음 (적은 매번 같은 행동을 하므로 생략) · 같은 정령이 둘이면 게임처럼 A·B로 구분

## 1. 처형의 사슬 (난이도 ★★★)

- 목표: 2라운드 안에 적 전부 처치
- 우리 편: 불사귀(신화 그림자), 그림자여왕(레전더리 숲결)
- 적: 로렐라이(에픽 물결), 주작(에픽 화염), 백사(레어 물결), 펜리르(레전더리 화염)
- 소개: 처형으로 적을 쓰러뜨리면 곧바로 한 번 더 행동. 처형을 사슬처럼 이어야 2라운드 안에 끝남.
- 힌트(게임): 첫 라운드에 셋을 정리해야 시간이 남음. 되살아나는 적은 마지막에 둘이 함께
- 풀이 요령(문서용): 여러 적의 체력을 먼저 30% 밑으로 깎아 두고, 처형을 연달아 이어 가기
- 찾은 서로 다른 해법 8가지

- 적이 쓰러지는 라운드(모든 해법 기준): 로렐라이 R1 · 주작 R1 · 백사 R1 · 펜리르 R2
- 처치 순서 · 노릴 적: 1R 로렐라이 · 주작 · 백사 처치 (처형으로 이어 가기) → 2R 펜리르 처치 — 둘이 함께 공격

| 라운드 | 행동 |
|---|---|
| R1 | **불사귀 처형 → 로렐라이** |
| R1 | **불사귀 생명 흡수 → 주작** |
| R1 | **그림자여왕 기본 공격 → 백사** |
| R2 | **불사귀 기본 공격 → 펜리르** |
| R2 | **그림자여왕 기본 공격 → 펜리르** |

- 우리 편: 불사귀(신화 그림자), 백록(신화 빛)
- 적: 세이렌(레전더리 물결), 대천사(에픽 빛), 주작(에픽 화염), 지신(레전더리 숲결)
- 소개: 되살리는 적과 치유하는 적이 서로를 지켜 줌.
- 힌트(게임): 앞줄은 처형으로 이어서 빠르게. 보호막을 거는 적은 2라운드 안에, 치유하는 적은 맨 마지막
- 풀이 요령(문서용): 무엇을 먼저 없앨지 정하기. 호령으로 처형 기회를 계속 이어 가기
- 찾은 서로 다른 해법 10가지

- 적이 쓰러지는 라운드(모든 해법 기준): 세이렌 R3 · 대천사 R2 · 주작 R1·R2 · 지신 R1·R2
- 처치 순서 · 노릴 적: 1~2R 주작 · 지신 처치 (앞줄이 살아 있으면 뒷줄은 못 노림 · 처형을 꼭 섞기) → 2R 대천사 처치 (찾은 해법 모두 2R 안에 처치, 넘기면 전부 실패) → 3R 세이렌 처치

| 라운드 | 행동 |
|---|---|
| R1 | **백록 기본 공격 → 주작** |
| R1 | **불사귀 기본 공격 → 지신** |
| R2 | **불사귀 처형 → 주작** |
| R2 | **불사귀 기본 공격 → 지신** |
| R2 | **백록 여명의 호령 → 아군 불사귀** |
| R2 | **불사귀 생명 흡수 → 대천사** |
| R3 | **불사귀 기본 공격 → 세이렌** |
| R3 | **백록 기본 공격 → 세이렌** |

## 10. 최후의 시련 (난이도 ★★★★★)

- 목표: 4라운드 안에 적 전부 처치 · 우리 편이 쓰러진 채로 남으면 실패
- 우리 편: 테티스(신화 물결), 백록(신화 빛), 불사귀(신화 그림자), 금오(신화 화염)
- 적: 현무(신화 숲결), 테티스(신화 물결), 광명(신화 빛), 스콜(신화 화염), 무닌(레전더리 그림자), 주작(에픽 화염)
- 소개: 탱커·치유·부활·폭발이 모두 모인 마지막 시련.
- 힌트(게임): 첫 라운드에 부활 폭발부터 받아 내기. 나머지는 지금까지의 요령 그대로
- 풀이 요령(문서용): 지금까지 쓴 요령을 모두 순서대로. 한 명도 잃지 말 것
- 찾은 서로 다른 해법 수천 가지 이상

- 적이 쓰러지는 라운드(찾은 해법 기준 · 해법이 너무 많아 일부만 확인): 현무 R1 · 테티스 R2·R3·R4 · 광명 R3·R4 · 스콜 R2 · 무닌 R3·R4 · 주작 R2
