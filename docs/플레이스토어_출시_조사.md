# 플레이 스토어 출시 조사 (2026-10-03 기준)

웹 검색으로 2026년 자료만 골라 정리함. 구글 고객센터(support.google.com)는 이 작업 환경에서 직접 열리지 않아서, 검색 결과에 나온 공식 문서 요약과 2026년 기사로 확인함 — 최종 확인은 Play Console 화면에서 다시 보는 게 안전함.

## 1. 결론부터

- **출시는 가능함.** 지금 게임은 웹앱(PWA)이라 **TWA(Trusted Web Activity)** 로 포장해서 올리는 게 가장 쉬움. 구글이 공식 지원하는 방법이고, 업데이트는 지금처럼 웹에 올리면 앱에도 바로 반영됨.
- **가장 큰 벽은 기술이 아니라 절차:**
  1. 새 개인 개발자 계정은 **테스터 12명이 14일 연속** 비공개 테스트에 참여해야 정식 출시 신청 가능
  2. **개인정보처리방침 페이지 · 계정 삭제 방법**이 있어야 함 (지금 게임엔 둘 다 없음)
  3. 돈을 받으려면(인앱 결제) 한국 개발자는 **사업자등록 + 통신판매업 신고**가 필요함
- **수익은 처음엔 광고보다 "무료 출시 → 반응 보기"가 현실적.** 인앱 결제를 붙이려면 코드 작업(Play 결제 연동)과 법적 준비가 같이 필요함.

## 2. 출시 절차

| 순서 | 할 일 | 비고 |
|---|---|---|
| 1 | Play Console 개발자 계정 만들기 (개인) | 등록비 25달러(1회). 2026년부터 **Android 개발자 인증(신원 확인)** 이 필수 절차로 들어감 — 신분증 확인 |
| 2 | 게임 주소의 도메인 맨 위에 `/.well-known/assetlinks.json` 올리기 | 지금 주소가 `dfdeer.github.io/AnimaRune/` 라서 **`dfdeer.github.io` 이름의 저장소를 새로 만들어** 거기에 올려야 함 (아니면 앱 위에 주소창이 보임). `.nojekyll` 파일도 같이 (점으로 시작하는 폴더를 GitHub Pages가 숨기지 않게) |
| 3 | Bubblewrap(구글 공식 도구) 또는 PWABuilder(웹 화면)로 앱 묶음(AAB) 만들기 | 둘 다 무료. **2026-08-31부터 새 앱·업데이트는 Android 16(API 36) 대상**이어야 함 → 최신 버전 도구로 만들 것 |
| 4 | 스토어 등록 정보 | 아이콘 512 · 대표 그림 1024×500 · 스크린샷 · 설명 |
| 5 | 앱 콘텐츠 설문 | **개인정보처리방침 주소**, **데이터 보안 양식**(어떤 정보를 모으는지), **계정 삭제 방법**, 콘텐츠 등급 설문(IARC — 한국 등급도 여기서 같이 나옴, 게임물관리위원회에 따로 안 내도 됨), 광고 포함 여부, 대상 연령 |
| 6 | **비공개 테스트: 테스터 12명 이상이 14일 연속** | 2023-11-13 이후 만든 개인 계정에 적용 (원래 20명 → 2024-12에 12명으로 줄어듦). 중간에 빠져서 12명 아래로 내려가면 그 날은 안 쳐 줌 → **15~20명 모으는 걸 추천** |
| 7 | 정식 출시(프로덕션) 신청 → 구글 검토 | 검토 통과하면 공개 |

### 우리 게임에서 미리 만들어야 하는 것
- **개인정보처리방침 페이지** — 구글 로그인(이메일 등)·익명 계정·서버 세이브·친구 기능이 있으니 무엇을 모으고 어떻게 지우는지 적어야 함. GitHub Pages에 페이지 하나로 만들면 됨.
- **계정 삭제** — 게임 안에서 계정을 만들 수 있으면(구글 연결·익명 계정) **게임 안 삭제 버튼 + 웹에서 삭제 요청하는 주소** 둘 다 필요. 지금은 없음 → Firebase의 세이브·친구·우편 데이터를 지우는 기능을 만들어야 함.
- **세이브 옮기기 안내** — 앱(TWA)은 크롬의 저장 공간을 같이 쓰긴 하지만, 기존 웹 세이브가 앱으로 그대로 넘어오는지는 **확인이 필요해요.** 구글 계정 연결(서버 세이브)로 옮기도록 안내하는 게 안전함.

## 3. 수익 창출

### 3-1. 인앱 결제 (유료 재화·패키지)
- **Play에서 디지털 상품을 팔면 Play 결제를 붙여야 함.** TWA에서는 **Digital Goods API + Payment Request API** 로 연결 (크롬 101 이상). 코드 작업 필요.
- **수수료 (2026년 바뀜, Epic 소송 합의):**
  - 새로 설치한 사용자의 인앱 결제 20% · 특정 프로그램 참여 시 15% · 구독 10%
  - 구글 결제를 쓰면 별도 결제 수수료(미국·영국·유럽 5%)
  - **한국은 2026년 말(12월 31일)부터 적용** — 그 전까지는 기존 방식. 한국에 실제로 적용되는 숫자는 그때 Play Console 공지로 확인이 필요해요.
- **한국 개발자가 유료 판매를 하려면:** 사업자등록번호 · 통신판매업 신고번호를 Play Console에 넣어야 함 (개인 계정이어도). 세금 신고도 따라옴.
- **확률형 아이템 확률 공개 (게임산업법, 2024-03-22 시행):** 돈 주고 사는 뽑기·강화·합성이 있으면 확률을 % 로 게임 안·광고에 표시해야 함. 위반 시 2년 이하 징역 또는 2천만원 이하 벌금. **단, 3년 연평균 매출 1억원 이하 중소기업은 제외.** 지금 게임은 소환 확률표가 이미 있어서 유료화해도 대응은 쉬움.
  - 지금처럼 **돈으로 사는 게 없으면** 이 법의 "유료 확률형 아이템"에는 해당하지 않음.

### 3-2. 광고
- 앱용 광고(AdMob)는 원래 앱 코드(네이티브)용이라, TWA(크롬으로 웹을 띄우는 방식)에 그대로 넣긴 어려움.
- 웹 게임용 **AdSense H5 게임 광고**(전면·보상형 광고, `adBreak()`)가 있음. 다만 **TWA 앱 안에서 이 광고를 쓰는 게 Play 정책·AdSense 정책상 괜찮은지는 확인이 필요해요.** (공식 문서는 "웹사이트 또는 앱 WebView에서" 라고만 되어 있고, TWA는 WebView가 아니라 크롬이라 따로 확인해야 함)
- 광고를 넣으면 앱 콘텐츠 설문에서 "광고 포함"으로 표시해야 함.

### 3-3. 현실적인 추천 순서
1. **무료(결제·광고 없음)로 먼저 출시** — 사업자등록 없이 개인 계정으로 가능. 테스터 12명 모으기 + 개인정보처리방침 + 계정 삭제만 준비하면 됨.
2. 반응을 보고 유료화 결정 → 사업자등록·통신판매업 신고 → Play 결제 연동 작업.

## 4. 알아 둘 변화 (2026)
- **Android 개발자 인증:** 2026-03부터 모든 개발자에게 열림. 2026-09-30부터 브라질·인도네시아·싱가포르·태국에서 인증 안 된 개발자의 앱 설치를 막고, 다른 나라는 2027년 이후. 플레이 스토어로 내면 Play Console 인증으로 해결됨.
  - 참고: 학생·취미용 **"제한 배포" 계정**은 신분증·등록비 없이 기기 20대까지 공유 가능 (플레이 스토어 공개 출시는 아님).
- **API 36 대상:** 2026-08-31부터 (연장 신청 시 2026-11-01까지).

## 5. 내가 할 수 있는 것 / 사용자가 해야 하는 것
- **내가:** 개인정보처리방침 페이지 · 게임 안 계정 삭제 기능 · `assetlinks.json` 파일 내용 · 스토어 설명문·스크린샷 준비 · Bubblewrap 설정 파일
- **사용자가:** 개발자 계정 등록·신원 인증·25달러 결제 · `dfdeer.github.io` 저장소 만들기 · 앱 서명 키 보관 · 테스터 12명 이상 모으기 · (유료화하면) 사업자등록·통신판매업 신고
- 앱 묶음(AAB) 빌드는 이 작업 환경에서 안드로이드 도구를 받을 수 있는지 **확인이 필요해요** (예전에 막혀 있었음). 안 되면 PWABuilder 웹사이트에서 사용자가 버튼으로 만들거나 GitHub Actions로 빌드.

## 6. AI로 만든 그림 신고 (사용자가 찾아온 내용 확인)

- **사실임.** Play Console에 **"AI 생성 콘텐츠 신고(Declaring AI-generated content)"** 공식 도움말이 있음.
  - 확인된 부분: 스토어 등록 정보·프로모션 콘텐츠에 올리는 **그림·영상마다** "AI로 만든 것인지" 체크하는 칸이 있음 (하나씩 따로 신고).
  - → 우리 게임은 정령·배경 그림을 AI로 만들었으니, **스크린샷·대표 그림을 올릴 때 해당 칸에 체크**하면 됨.
- **앱 안 표시는 다른 문제:** 2026-04-15부터 적용된 규칙은 **앱이 실행 중에 AI로 글·그림을 만들어 보여 주는 경우**(챗봇, 그림 생성기 등) 결과물 옆에 AI 표시 + 신고 기능을 넣으라는 내용 (2026-07-15부터 외부 AI API를 쓰는 앱도 포함).
  - 우리 게임은 실행 중에 AI로 만드는 게 없고, 미리 만든 그림을 넣은 것뿐이라 **이 규칙에는 해당하지 않을 가능성이 높음.** 다만 Play Console 설문 문구를 직접 보고 답해야 해서 **확인이 필요해요.**
  - 캡처에 나온 "정책 > 앱 콘텐츠 > AI 생성 콘텐츠 설문"은 구글 검색 AI 요약이라, 메뉴 위치·이름은 실제 Play Console에서 다시 확인해야 함 (공식 도움말 요약에는 스토어 등록 화면의 체크 칸으로 나와 있음).
