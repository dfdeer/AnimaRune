# 아니마룬 이미지 요청서 (ChatGPT 이미지 생성용)

## 쓰는 방법

1. **블록 하나 = 메시지 하나 = 이미지 한 장**이에요. 회색 코드 상자 안의 내용을 통째로 복사해서 보내면 돼요.
2. 블록마다 공통 규칙(그림체·크기·배치·투명 배경)이 전부 들어 있어요. 한도에 걸려 **새 채팅방에서 이어서 해도** 똑같이 나오게 하기 위해서예요.
3. **그림체 고정 팁:** 마음에 든 이미지(예: 지난번 4번 사진)를 같이 첨부하고, 코드 상자 맨 위에 다음 한 줄을 붙이면 그림체가 덜 흔들려요.
   `첨부한 그림의 그림체만 참고해줘 (크기와 자세는 따라 하지 말 것).`
4. 받은 이미지는 아래 **검수 체크리스트**로 확인하세요. 문제가 있으면 **다시 뽑지 말고 수정 요청 문구**를 보내세요. 처음부터 다시 뽑으면 또 다른 문제가 생겨요.
5. 정령 시트는 한 장에 5마리가 들어 있어요. 게임에 넣을 때는 칸별로 잘라서 한 마리씩 파일로 만들어야 해요. 블록마다 파일 이름을 적어 두었어요.

## 지난번 결과에서 고친 점

| 문제 | 이번 요청서에서 막은 방법 |
|---|---|
| 1번: 구도가 다 똑같고, 커지고 이펙트만 늘어남 | 단계마다 **자세·실루엣·얼굴·소품을 각각 다르게 지정**했어요. 같은 자세나 고개 각도를 다시 쓰지 말라고 명시했어요. |
| 2번: 너무 큼, 배경 있음 | 칸 크기를 기준으로 **1단계 50% → 5단계 75%(최대 1.5배)**로 숫자를 정했어요. 이펙트까지 포함해서 재요. 투명 배경을 요구하고 이름 글자는 금지했어요. |
| 3번: 여전히 큼, 그림체가 너무 빡셈 | **귀여운 캐주얼 치비체, 굵은 외곽선, 2~3단 명암, 디테일 낮게**로 고정했어요. 64px로 줄여도 알아보게 하라고 했어요. |
| 4번: 3단계와 4단계가 거의 같음 | 3단계와 4단계는 자세·얼굴·실루엣이 **확실히 달라야 한다**고 따로 적었어요. 줄마다 3·4단계를 정반대 자세로 지정했어요 (예: 낮게 버틴 돌진 ↔ 공중 도약). |
| 4번: 투명 배경 대신 **체크무늬를 그려 넣음** | "체크무늬를 그리지 말 것"을 명시했어요. |

## 검수 체크리스트 (받을 때마다)

- [ ] 5마리가 3×2 칸에 한 마리씩 있고, 오른쪽 아래 칸은 비어 있나?
- [ ] 제일 큰 5단계가 1단계의 1.5배를 넘지 않나? (이펙트 포함)
- [ ] 5마리 자세가 전부 다르나? 특히 3단계와 4단계를 가려도 구분되나?
- [ ] 얼굴(눈 모양·표정)이 단계마다 다르나?
- [ ] 같은 종으로 보이나? (색감과 블록에 적힌 공통 특징이 유지되나)
- [ ] 배경이 진짜 투명인가? (체크무늬·흰 배경·바닥 그림자 없음)
- [ ] 글자·이름표가 없나?
- [ ] 5마리 모두 같은 방향(정령은 왼쪽)을 보고 있나?

## 수정 요청 문구 (그대로 복사해서 쓰기)

- **크기:** `다른 건 전부 그대로 두고 캐릭터 크기만 줄여줘. 이펙트 포함해서 1단계는 칸 높이의 50%, 5단계는 75%. 5단계가 1단계의 1.5배를 넘으면 안 돼.`
- **3·4단계가 비슷함:** `1, 2, 5단계는 그대로 두고 3단계와 4단계만 다시 그려줘. 바로 앞 메시지에 적은 대로 자세·얼굴·실루엣이 확실히 달라야 해.`
- **체크무늬:** `배경에 체크무늬가 그려져 있어. 체크무늬를 지우고 진짜 투명 PNG(알파 채널)로 줘. 투명이 안 되면 대신 단색 흰 배경으로 줘.`
- **그림체가 빡셈:** `너무 세밀해. 더 단순하고 귀여운 치비체로 다시 그려줘. 굵고 깔끔한 외곽선, 2~3단계의 단순한 셀 명암, 털·비늘 질감 없이.`
- **한 마리만 이상함:** `다른 캐릭터는 전부 그대로 두고 N단계만 다시 그려줘: (고칠 점).`

> 투명 배경은 ChatGPT가 매번 지켜준다는 보장이 없어요. 계속 안 되면 흰 배경으로 받으세요. 나중에 게임에 넣을 때 배경 지우기를 시도할 수 있는데, 불꽃처럼 가장자리가 흐린 부분이 깔끔하게 지워질지는 **해봐야 알아요**.

## 1부. 정령 10종 (블록 1~10)

칸 순서: 윗줄 **일반 · 레어 · 에픽**, 아랫줄 **레전더리 · 신화 · (빈칸)**

### 블록 1. 화염 A — 늑대과 (돌격)

단계별 핵심 차이 (확인용):
- 잉걸: 앉아 있는 동글동글 새끼, 꼬리 끝 불씨
- 하랑: 엉덩이 치켜든 장난 자세, 불꽃 갈기 시작
- 볼칸: 낮게 버틴 돌진 자세, 어깨 화산암 판
- 펜리르: 공중 도약, 한쪽 다리에 끊어진 사슬
- 스콜: 앞발 하나 든 당당한 자세, 머리 뒤 작은 태양

```text
[그림체 — 모든 시트 동일]
귀엽고 캐주얼한 모바일 게임 캐릭터. 치비 비율(머리 크고 몸 작게), 깔끔하고 진한 외곽선, 2~3단계의 단순한 셀 명암, 단순한 형태, 낮은 디테일, 밝고 또렷한 색.
사실적인 그림 금지, 회화풍 금지, 털·비늘 질감 묘사 금지, 극적인 조명 금지.
64×64픽셀로 줄여도 무슨 캐릭터인지 알아볼 수 있어야 함.

[캔버스]
1536×1024 PNG, 배경은 진짜 투명(알파 채널).
체크무늬(투명을 흉내 낸 회색 격자) 그리지 말 것. 바닥, 그림자, 배경 풍경, 테두리, 글자, 이름표 전부 넣지 말 것.

[배치]
보이지 않는 3×2 칸(한 칸 512×512)으로 나눔.
윗줄 왼쪽부터: 1단계, 2단계, 3단계. 아랫줄 왼쪽부터: 4단계, 5단계, 오른쪽 아래 칸은 비워 둠.
한 칸에 한 마리씩 가운데에. 불꽃·날개·꼬리·입자 이펙트도 다른 칸으로 넘어가면 안 됨.

[크기 — 반드시 지킬 것]
이펙트까지 포함해서 캐릭터 높이를 잼.
1단계 = 칸 높이의 50%, 2단계 = 55%, 3단계 = 60%, 4단계 = 67%, 5단계 = 75%.
5단계는 절대 1단계의 1.5배를 넘으면 안 됨. 성장은 크기나 이펙트 양이 아니라 디자인(형태·장식·무늬)으로 표현할 것.

[방향]
다섯 마리 모두 3/4 정면 구도. 몸은 보는 사람 기준 왼쪽을 향하고, 얼굴은 보는 사람을 봄. 다섯 마리 모두 같은 방향.

[진화 — 가장 중요]
다섯 마리는 같은 종이 진화하는 것(아래 색감과 공통 특징은 유지). 하지만 단계마다 한눈에 다른 캐릭터로 보여야 함:
- 자세가 전부 달라야 함 (같은 자세·같은 고개 각도 재사용 금지)
- 실루엣과 몸 비율이 달라야 함
- 얼굴(눈 모양, 표정, 입)이 달라야 함
- 단계마다 대표 장식이나 특징이 하나씩 달라야 함
특히 3단계와 4단계는 "이펙트만 늘어난 것"이 아니라 자세·얼굴·실루엣이 확실히 달라야 함.

[종] 화염 A — 늑대과. 역할: 앞뒤 안 가리고 돌진하는 공격수 (스킬: 투지, 불꽃 돌진, 분화).
색감: 숯처럼 검은 털, 빨강·주황 불꽃, 빛나는 용암 균열 무늬.
모든 단계 공통 특징: 불꽃 모양 꼬리 끝, 호박색 눈.

[단계별 디자인]
1단계 — 잉걸 (일반): 동글동글한 털뭉치 새끼 늑대가 앉아 있음. 고개를 갸웃, 아주 큰 동그란 눈, 입 벌리고 해맑게 웃음. 불은 꼬리 끝의 작은 불씨 하나뿐. 가장 순하고 무해해 보이게.
2단계 — 하랑 (레어): 다리가 길쭉한 청소년 늑대. 앞다리는 낮추고 엉덩이는 치켜든 장난치는 자세. 한쪽 귀에 V자 흠, 송곳니 하나 보이는 장난스러운 웃음, 목에 작은 불꽃 갈기가 막 생김.
3단계 — 볼칸 (에픽): 땅딸막하고 묵직한 늑대가 머리를 숙이고 낮게 버틴 돌진 자세. 어깨와 등에 화산암 판, 그 위에 작은 연기 구멍. 가늘고 엄한 눈, 입은 다묾.
4단계 — 펜리르 (레전더리): 날렵하고 다리 긴 늑대가 네 발이 모두 땅에서 떨어진 공중 도약 순간. 입을 크게 벌림, 길게 휘날리는 불꽃 갈기, 한쪽 앞다리에 끊어진 금색 족쇄와 사슬 고리. 날카롭고 가는 눈.
5단계 — 스콜 (신화): 위엄 있는 늑대가 앞발 하나를 들고 당당하게 서 있음. 입을 다문 여유로운 미소, 얼굴에 금색 햇살 무늬, 짧은 불꽃 꼬리 세 개, 머리 뒤에 작은 태양 원반이 후광처럼 떠 있음.

위 조건대로 이 시트 한 장을 그려줘.
```

자를 때 파일 이름: `fire_common_a.png`(잉걸), `fire_rare_a.png`(하랑), `fire_epic_a.png`(볼칸), `fire_legendary_a.png`(펜리르), `fire_mythic_a.png`(스콜)

## 6부. 버튼·패널과 글꼴 (이미지 요청 없음)

### 버튼·창 테두리
- **이미지로 만들지 않는 것을 추천해요.** 버튼은 글자 길이에 따라 크기가 달라지는데, 그림으로 만든 버튼을 늘리면 모서리가 뭉개지거나 흐려져요.
- 대신 위 아이콘·등급 테두리 그림체(굵은 외곽선, 둥근 모서리, 위쪽 하이라이트)에 맞춰서 **게임 코드(CSS)로 버튼 모양을 다시 그리는 게** 선명하고 가벼워요. 이미지가 다 모이면 제가 맞춰서 바꿀 수 있어요.

### 글꼴
- 이미지 생성 AI는 **글꼴 파일을 만들 수 없어요.** 글꼴은 무료 글꼴을 골라 쓰는 게 맞아요.
- 귀여운 캐주얼 게임에 어울리는 한글 무료 글꼴 후보 (구글 폰트, 상업적 사용 가능한 OFL 라이선스):
  - **Jua (주아)** — 둥글고 귀여움. 버튼·제목용
  - **Do Hyeon (도현)** — 굵고 또렷함. 숫자·제목용
  - **Gowun Dodum (고운돋움)** — 부드럽고 읽기 편함. 설명 글용
- 지금 게임은 기기 기본 글꼴을 쓰고 있어요. 고르시면 제목은 Jua, 본문은 기본 글꼴처럼 나눠서 적용할 수 있어요. 라이선스는 적용할 때 구글 폰트 페이지에서 한 번 더 확인할게요.
