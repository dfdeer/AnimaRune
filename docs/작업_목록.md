# 작업 목록 (서바이벌 1.0.0~)

버전은 `주.부.수` 세 자리로, 새 콘텐츠는 앞자리, 기존 콘텐츠 큰 변경과 밸런스는 가운데, 자잘한 수정은 끝자리.
**지금은 다듬는 중이라 `APP_VERSION`은 1.0.0 그대로, `APP_BUILD`와 `CACHE`만 올림** (사용자가 패치 노트를 다시 쓰라고 할 때부터 버전 규칙 적용).
끝낸 건 지우고, 새 요청은 알맞은 칸에 추가.

예전 아니마룬 할 일(균열, 레이드, 성역, 정령 마을 등)은 1.0.0에서 화면에서 숨겨 이 목록에서 뺐어. 필요하면 git 기록에서 build 675 전의 이 문서를 보면 됨.

## 🆕 새 콘텐츠 (앞자리)

1. **맵 셋 더 (화산, 유적, 심연)** — 그림을 받으면 맵 편집기(https://claude.ai/artifact/9EzHxpe75dgH3sXmyHZepD)의 `MAPS[맵].dir`에 올리고, 사용자 배치를 받아 게임에 넣고 `SV_STAGE_READY` 늘림 · 그림 요청서 https://claude.ai/artifact/7AGkbwNGcfUXCkma1e7qm5 · 맵마다 기믹 아이디어는 아래
   1. 화산: 용암과 분화, 불씨 돌을 날라 화염 포대 채우기, 주기적으로 잠기는 용암 다리
   2. 유적: 가시 함정, 함께 걷는 수호 석상 아군, 석판 차례로 밟기, 거울을 돌려 빛줄기
   3. 심연: 어둠, 순간이동 문, 반딧불 등불(켜면 둘레가 밝고 적이 약해짐), 내 길을 따라오는 그림자 분신, 중력 우물
2. **트리의 남은 칸** — 융합 제단 5, 융합 정령 5(새 그림과 기술 필요), 동행의 맹세 · 지금은 「준비 중」
3. 다음 후보(사용자가 고름): 성좌 계열 룬, 무작위 이벤트와 퀘스트, 보스 기믹 더, 판 길이
