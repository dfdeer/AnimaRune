# 계정 연동 설정 (Firebase 관리 화면)

게임 코드는 준비돼 있어요. 아래 3가지를 Firebase 관리 화면(console.firebase.google.com → spirit summoner 프로젝트)에서 켜야 실제로 동작해요.

> **규칙은 이제 `docs/Firebase_규칙.md`에 전체본(설명 주석 포함)으로 모아 둠** — 규칙 탭을 통째로 바꿀 때는 그 문서를 쓰면 됨. 아래 3·4번은 예전에 부분만 추가하던 안내.

## 1. 구글 로그인 켜기
1. 왼쪽 메뉴 **Authentication** → 위쪽 **로그인 방법** 탭
2. **새 제공업체 추가** → **Google** → **사용 설정** 켜기
3. 프로젝트 지원 이메일 선택 → **저장**

## 2. 게임 주소 허용
1. **Authentication** → **설정** 탭 → **승인된 도메인**
2. **도메인 추가** → `dfdeer.github.io` 입력 → 추가

이게 없으면 게임에서 "이 주소가 허용되지 않았어요"라고 떠요.

## 3. 서버 세이브 저장 규칙 추가
1. 왼쪽 메뉴 **Realtime Database** → **규칙** 탭
2. 지금 있는 규칙의 맨 바깥 `"rules": { ... }` 안에 아래 두 덩어리를 **추가**해요. 기존 내용은 지우지 마세요.

```json
"saves": {
  "$uid": {
    ".read": "auth != null && auth.uid === $uid",
    ".write": "auth != null && auth.uid === $uid"
  }
},
"sessions": {
  "$uid": {
    ".read": "auth != null && auth.uid === $uid",
    ".write": "auth != null && auth.uid === $uid"
  }
}
```

앞 덩어리 끝에 쉼표(`,`)가 필요해요. 붙여넣은 뒤 **게시**를 눌러요.

- `saves` = 서버 세이브 (본인만 읽고 쓰기)
- `sessions` = 지금 이 계정으로 하고 있는 기기 (한 번에 한 기기)

같은 곳에서 친구 창 대표 정령도 확인해 주세요. `players/<uid>` 아래에 `rep`를 본인이 쓸 수 있어야 보여요.

## 게임에서 쓰는 법
- **설정 → 계정 → 구글로 연동하기**
- 처음 기기: 지금 진행이 그대로 서버에 올라가요.
- 다른 기기: 같은 버튼을 누르면 그 계정으로 바뀌고 서버 진행을 불러와요.
- 양쪽 진행이 다르면 "어떤 진행으로 할까요?" 창에서 골라요. 고르지 않은 쪽은 사라져요. 단, 이 기기 것은 기기 안에 따로 보관돼요.
- 같은 계정으로 다른 기기에서 접속하면, 먼저 켜둔 기기는 "다른 기기에서 접속했어요" 창이 뜨고 저장을 멈춰요.

## 4. 우편함 규칙 (관리자만 우편 보내기)

게임 화면의 관리자 버튼은 친구 코드 `N6RAK876`인 계정에만 보여요. 하지만 화면에서 숨기는 것만으로는 막을 수 없어서, **서버 규칙으로 관리자만 우편을 쓸 수 있게** 해야 해요.

### 내 계정 번호(UID) 찾기
1. **Realtime Database** → **데이터** 탭
2. `friendCodes` → `N6RAK876`을 누르면 오른쪽 값이 내 UID예요. 예: `aBcD1234...`

### 규칙 추가
**규칙** 탭의 `"rules": { ... }` 안에 아래를 **추가**해요. `관리자UID` 자리에 위에서 찾은 값을 넣어요(따옴표는 그대로).

```json
"mail": {
  "all": {
    ".read": "auth != null",
    "$id": { ".write": "auth != null && auth.uid === '관리자UID'" }
  },
  "user": {
    ".read": "auth != null && auth.uid === '관리자UID'",
    "$uid": {
      ".read": "auth != null && auth.uid === $uid",
      "$id": {
        ".write": "auth != null && ((auth.uid === '관리자UID' && (!data.child('c').exists() || !newData.exists())) || (auth.uid === $uid && !newData.exists()))",
        "c": { ".write": "auth != null && auth.uid === $uid && !data.exists() && newData.isNumber() && data.parent().child('title').exists()" }
      }
    }
  }
}
```

- `mail/all` = 모든 플레이어 우편: 누구나 읽기, 관리자만 쓰기
- `mail/user/<UID>` = 개인 우편: 본인과 관리자만 읽기, 관리자만 보내기
  - 본인은 받으면 `c`(받은 시각)만 적을 수 있음 → 받은 우편도 보관 기간까지 남음 (v2.10.5~)
  - 관리자는 `c`가 없는(아직 안 받은) 우편만 수정 가능 · 삭제는 언제든
- (v2.10.5) 위 규칙으로 바꿔야 관리자 '보낸 우편 관리 → 개인 우편' 탭이 보이고, 받았는지가 표시돼요. `docs/firebase_database_rules.json`에 실제 값이 들어간 전체 규칙이 있어요.

### 주의
- 구글 연동을 하면 계정 번호가 **그대로 유지**돼요. 이미 다른 기기에서 연동한 구글로 바꾸면 그 계정의 번호가 되니, 관리자 기기에서 친구 코드가 `N6RAK876`인지 다시 확인해주세요.
- 관리자 세팅(재화 최대치·모든 해금·정령 1마리씩)은 그 기기의 세이브에만 적용돼요.
