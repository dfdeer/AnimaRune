# 성역 기획 (새 콘텐츠 · 미리 준비)

- 2026-10-03 · 사용자 결정: 균열을 늘리는 대신 **새 보스 모드 「성역」** 을 만듦. 지금은 하드 5를 깨는 사람이 적어서 **코드·그림만 미리 준비하고 출시는 나중** (`SANCTUM_ON` 스위치로 숨김)
- 목적: 정령을 다 키운 뒤 "싸워서 강해지는 느낌" — 처음 보는 기믹 + 단계마다 높아지는 보상 + 모으는 문장

## 1. 기본 규칙

| 항목 | 내용 |
|---|---|
| 열리는 조건 | 하드 5 챕터 보스(그림자 군주 하드) 처치 |
| 구성 | 수호자 6명 × 단계 1~10 |
| 도전 | 횟수 제한 없음 · 진형은 탐험과 같은 6칸 |
| 단계 | 1단계 = 하드 5 보스 수준 · 단계마다 체력·공격력 +18% (10단계 ≈ 4.4배) — 시뮬로 다시 맞춤 |
| 첫 클리어 보상 | 단계마다 1번: 정수 4,000×단계 · 강화석 120×단계 · 별빛 조각 15×단계 · 10단계는 정수 +20,000 · 별빛 조각 +100 더 |
| 문장 | 수호자마다 깬 단계 수 = 문장 단계 (능력치 없음 · 모으는 메달) · 성역 화면과 내 프로필에 표시 — (사용자 결정 2026-10-03: 영구 능력치는 결투·기존 콘텐츠 밸런스를 흔들어서 뺌) |
| 추천 전투력 | 단계마다 표시 (시뮬로 잼) |

## 2. 수호자 6명 — 처음 보는 기믹

| # | 이름 | 속성 | 기믹 (지금 게임에 없는 것) | 빛나는 정령 |
|---|---|---|---|---|
| 1 | 야누스 (두 얼굴) | 빛 → 그림자 | **2단계 전투**: 체력 50%에서 얼굴이 바뀌며 속성이 그림자로 바뀌고 스킬 2개가 통째로 바뀜. 바뀌는 순간 걸린 해로운 효과를 전부 털어 냄 | 속성을 섞은 팀 · 칠흑조 저주 |
| 2 | 카스토르·폴룩스 (쌍둥이) | 화염 · 물결 | **보스 둘**: 한쪽이 먼저 쓰러지면 2라운드 뒤 남은 쪽이 체력 50%로 되살려 냄 → 둘을 2라운드 안에 같이 쓰러뜨려야 함. 남은 쪽은 그동안 공격력 +40% | 범위 공격 · 스칼렛 연쇄 점화 · 범람 |
| 3 | 에코 (거울) | 무속성 | **복제**: 전투 시작에 우리 팀에서 전투력이 가장 높은 정령을 그대로 복제해 적으로 세움 (같은 스킬, 체력 1.5배). 복제가 살아 있는 동안 보스가 받는 피해 −40% | 약한 정령도 고루 키운 팀 · 로키 강탈 |
| 4 | 아틀라스 (무너지는 하늘) | 숲결 | **붕괴 표식**: 2라운드마다 아군 하나에 표식 → 다음 라운드 시작에 최대체력 60% 피해. 표식 받은 정령이 그 라운드 안에 보스를 때리면 표식이 보스에게 넘어감 (보스가 대신 받음) | 빠른 정령 · 백록 호령 · 도깨비 자리 바꾸기 |
| 5 | 프리즘 (일곱 빛) | 순환 | **약점 순환**: 라운드마다 약점 속성이 바뀜 (예고 표시) — 약점 속성 공격은 2배, 나머지는 0.5배 | 다섯 속성을 섞은 팀 · 아스트라이아 표식 모았다 터뜨리기 |
| 6 | 레기온 (군단의 왕) | 그림자 | **군단**: 라운드마다 졸개 2마리를 뒷줄에 불러냄 (최대 4). 졸개가 2마리 이상이면 보스 받는 피해 −50% · 졸개는 3라운드 뒤 자폭 | 범위 공격 · 도깨비 끌어내기 · 산군 반격 |
