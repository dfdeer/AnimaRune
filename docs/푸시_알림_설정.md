# 휴대폰 푸시 알림 설정 (Cloudflare Workers · 무료 · 카드 없음)

게임은 알림을 **받는 쪽**만 하고, **보내는 쪽**은 Cloudflare에 올린 작은 서버([../cloudflare/push-worker.js](../cloudflare/push-worker.js))가 해.
아래 설정을 다 하기 전까지는 게임 설정 창에 🔔 버튼이 **안 보임** (서버 주소·공개 키가 DB에 생겨야 보임).

## 무엇을 보내나
| 종류 | 언제 | 속도 |
|---|---|---|
| 🙋 친구 요청 · 🤝 수락 | 요청·수락을 보낸 직후 | 바로 (몇 초) |
| 📮 개인 우편 | 관리자가 보낸 직후 | 바로 |
| 📮 전체 우편 | 관리자가 보낸 뒤 1분마다 25명씩 | 몇 분 |
| 💬 문의 답장 / 📨 새 문의(관리자) | 쓴 직후 | 바로 |
| 🔥 화로 가득 · 🧭 파견 완료 | 게임이 기록한 시각 | 최대 1분 늦음 |
| 🌅 일일 | 다음 날 낮 12시 (그 전에 게임을 열면 하루 뒤로 밀림) | 최대 1분 늦음 |
| 🎉 큰 업데이트 | 배포된 버전의 앞자리가 오를 때(예: 5.0.0) 한 번 — 서버가 10분마다 `sw.js` 확인 (v5.0.4) | 몇 분~10분 |

- 알림은 그 기기에서 켠 사람만 받고, 종류별로 끌 수 있어 (설정 → 🔔 휴대폰 알림).
- 아이폰은 iOS 16.4 이상 + **Safari 공유 → 홈 화면에 추가**한 앱에서만 받을 수 있음 (애플 정책).
- 가짜 알림 방지: 게임이 서버를 깨우면 서버가 DB에서 그 항목이 진짜 있는지·15분 안에 생긴 건지 확인하고, 같은 알림은 한 번만 보냄.

## 무료 한도 (Cloudflare Workers Free)
- 하루 요청 10만 회 · 예약 실행 계정당 5개(이 서버는 1개) · 카드 등록 없음 → 한도를 넘어도 돈이 나가지 않고 그날만 멈춤.
- 이 서버 사용량: 예약 실행 하루 1,440회 + 알림 보낼 때마다 1회.

## 처음 한 번 해야 하는 것 (약 15분)

### 1. Firebase 규칙 붙여 넣기
- [Firebase_규칙.md](Firebase_규칙.md)의 규칙 전체를 Firebase 콘솔 → Realtime Database → **규칙** 탭에 통째로 붙여 넣고 **게시**.

### 2. Firebase 데이터베이스 비밀 키 복사
1. Firebase 콘솔 → 왼쪽 위 ⚙️ → **프로젝트 설정**
2. 위쪽 탭 **서비스 계정** → 왼쪽 **데이터베이스 비밀번호**(Database secrets)
3. 비밀번호 줄의 **표시** → 나온 긴 문자열 복사 (메모장에 잠깐 붙여 두기 — **아무에게도 보여 주지 말 것**)

### 3. Cloudflare 가입
- https://dash.cloudflare.com/sign-up → 이메일·비밀번호로 가입 → 메일 인증 (카드 필요 없음)

### 4. 알림 서버 만들기
1. Cloudflare 대시보드 왼쪽 메뉴 **Compute (Workers)** → **Workers & Pages** → **만들기(Create)**
2. **Hello World로 시작(Start with Hello World)** → 이름을 `animarune-push`로 → **배포(Deploy)**
3. 다 되면 **코드 편집(Edit code)** → 왼쪽 파일(`worker.js`)의 내용을 전부 지우고,
   https://raw.githubusercontent.com/dfdeer/AnimaRune/main/cloudflare/push-worker.js 를 열어 나온 글자 전체를 복사해서 붙여 넣기
4. 오른쪽 위 **배포(Deploy)**

### 5. 변수 넣기
1. 방금 만든 `animarune-push` → **설정(Settings)** → **변수 및 비밀(Variables and Secrets)** → **추가(Add)**
2. 두 개 추가 후 **배포(Deploy)**:
   | 종류 | 이름 | 값 |
   |---|---|---|
   | 텍스트(Text) | `DB_URL` | `https://spirit-summoner-4e7e1-default-rtdb.asia-southeast1.firebasedatabase.app` |
   | 비밀(Secret) | `DB_SECRET` | 2번에서 복사한 비밀 키 |

### 6. 1분마다 실행 켜기
- `animarune-push` → **설정(Settings)** → **트리거 이벤트(Trigger Events)** 또는 **트리거(Triggers)** → **Cron 트리거 추가** → 직접 입력 `* * * * *` (1분마다) → 추가

### 7. 준비 완료 확인
- 주소창에 `https://animarune-push.<내 계정 이름>.workers.dev/setup` 열기
  (정확한 주소는 `animarune-push` 화면 위쪽에 나와 있음 — 뒤에 `/setup`만 붙이기)
- **"아니마룬 알림 서버 준비 완료"**가 나오면 성공 → 서버 키와 주소가 DB에 저장됨

### 8. 게임에서 켜기
- 게임을 새로고침 → ☰ 설정 → **🔔 휴대폰 알림** → 알림 켜기 → 권한 허용
- 확인: 관리자 우편으로 나에게 개인 우편을 보내 보기 → 몇 초 안에 알림이 오면 성공

## 서버 코드가 바뀌었을 때
- 4번의 3~4만 다시 (코드 전체 붙여 넣기 → 배포). 변수·트리거는 그대로 남음.

## 문제가 생기면
- `animarune-push` → **로그(Logs)** 에서 `push fail` · `error` 찾기
- 게임에서 알림을 껐다 켜면 그 기기 주소를 다시 등록함
- 비밀 키가 새어 나갔다면: Firebase 2번 화면에서 비밀번호를 지우고 새로 만든 뒤 5번의 `DB_SECRET`만 바꾸기
