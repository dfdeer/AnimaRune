# 휴대폰 푸시 알림 설정 (v3.3.0)

게임은 알림을 **받는 쪽**만 하고, **보내는 쪽**은 Firebase 함수(`functions/index.js`)가 해. 함수는 한 번 배포하면 계속 돌아가.

## 무엇을 보내나
| 종류 | 언제 | 보내는 방식 |
|---|---|---|
| 🙋 친구 요청 | `friendReqs/<받는 사람>/<보낸 사람>`이 생길 때 | 바로 |
| 📮 우편 | 개인 우편(`mail/user`) · 전체 우편(`mail/all`)이 생길 때 | 바로 |
| 💬 문의 | 관리자 답장 → 문의한 사람 · 새 문의·이어 쓴 글 → 관리자 | 바로 |
| 🔥 화로 가득 | 게임이 기록한 가득 차는 시각 | 10분마다 확인 |
| 🧭 파견 완료 | 가장 먼저 끝나는 파견 시각 | 10분마다 확인 |
| 🌅 일일 | 다음 날 낮 12시 (그 전에 게임을 열면 다시 하루 뒤로 밀림) | 10분마다 확인 |

- 이 기기에서 알림을 켠 사람만 받음 (설정 → 🔔 휴대폰 알림). 종류별로 끌 수 있음.
- 아이폰은 iOS 16.4 이상 + **Safari 공유 → 홈 화면에 추가**한 앱에서만 받을 수 있음 (애플 정책).
- 서버 키(VAPID)는 함수가 처음 실행될 때 스스로 만들어서 `pushCfg/vapid`에 저장해. 따로 넣을 비밀 값은 없어.

## 처음 한 번 해야 하는 것

### 1. 요금제를 Blaze로 바꾸기
- Firebase 콘솔 → 왼쪽 아래 **업그레이드** → Blaze(사용한 만큼 지불) → 결제 계정(카드) 연결.
- 함수는 Blaze에서만 배포할 수 있어. 무료 사용량이 있어서 이 게임 규모면 0원일 가능성이 높아:
  - 함수 호출 월 200만 회 무료 (10분마다 확인 = 월 약 4,300회 + 알림 보낼 때마다)
  - 예약 실행(Cloud Scheduler) 작업 3개 무료 (이 게임은 1개 씀)
- **예산 알림 추천:** Google Cloud 콘솔 → 결제 → 예산 및 알림 → 예: 1,000원 넘으면 메일. (예산 알림은 메일만 보내고 자동으로 막지는 않음)

### 2. 규칙 붙여 넣기
- `docs/Firebase_규칙.md`의 규칙 전체를 Realtime Database → 규칙 탭에 붙여 넣고 게시. (v3.3.0에서 `push`·`pushCfg` 추가)

### 3. 함수 배포 (브라우저만 있으면 됨 — Cloud Shell)
1. https://console.cloud.google.com 접속 → 위쪽에서 프로젝트 **spirit-summoner-4e7e1** 선택
2. 오른쪽 위 **`>_` (Cloud Shell 활성화)** 버튼 → 아래에 터미널이 열림
3. 아래를 한 줄씩 붙여 넣고 엔터:
   ```
   git clone https://github.com/dfdeer/AnimaRune.git
   cd AnimaRune/functions && npm install && cd ..
   npx firebase-tools login --no-localhost
   npx firebase-tools deploy --only functions --project spirit-summoner-4e7e1
   ```
   - `login`은 주소를 하나 띄워 줌 → 열어서 구글 로그인 → 나온 코드를 터미널에 붙여 넣기
   - 처음 배포 때 필요한 기능(Cloud Functions·Cloud Build·Artifact Registry·Cloud Scheduler·Eventarc 등)을 켤지 물으면 **Y**
   - "컨테이너 이미지 정리 정책" 질문이 나오면 기본값(며칠 지나면 지움)으로 — 저장 비용을 막아 줌
   - 처음엔 기능을 켜는 데 몇 분 걸려서 실패할 수 있음 → 2~3분 뒤 마지막 줄만 다시
4. 끝나면 `✔ Deploy complete!`
5. **10분쯤 기다리기** — 예약 함수가 처음 돌면서 서버 키(`pushCfg/pub`)를 만듦. 그 전에 알림을 켜면 "알림 서버 준비 전"이라고 나옴.

### 4. 확인
- 휴대폰 게임 → ☰ 설정 → 🔔 휴대폰 알림 → 알림 켜기 → 권한 허용
- 관리자 우편으로 나에게 개인 우편을 보내 보기 → 몇 초 안에 알림이 오면 성공

## 나중에 함수를 고쳤을 때
Cloud Shell에서:
```
cd AnimaRune && git pull && cd functions && npm install && cd .. && npx firebase-tools deploy --only functions --project spirit-summoner-4e7e1
```

## 문제가 생기면
- Firebase 콘솔 → Functions → 로그에서 `push fail` 찾기
- 알림을 껐다 켜면 그 기기 주소를 다시 등록함
