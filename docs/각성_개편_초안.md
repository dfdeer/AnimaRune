# 각성 개편 초안 2차 (v8.7.0 예정 · 사용자 확인 전)

## 방향 (10/9 사용자 결정)
- 지금 각성 ★5 계열 효과(`AWAKEN5`) → **1단계**로 옮김
- **3단계**에 비슷한 크기의 계열 효과 하나 더 (계열 전체 — 일반~신화 다 받음)
- **5단계 고유 패시브** — 신화·성좌만 / **성좌 승급** → 고유 패시브 강화 / 한정 성좌는 5단계 하나
- 밸런스 시뮬은 다시 안 맞춤 · 부활 순서 같은 설명은 문구에 안 넣음
- 부활을 자꾸 넣지 말 것 (수르트 피드백)
- 로키·도깨비는 1단계 이동만 · 3·5단계는 나중에

## 스킬 변경 (각성과 별개 — 모두 적용)

### 하백 범람 — 아군에게도
- 적에게: 지금 그대로 (전체 공격력 90% + 수위 30% 추가 + 둔화)
- 아군에게: 아군 전체에 같은 양만큼 회복(공격력 90% + 수위 30%) + 가속 (속도 +10, 2라운드)
- 필요한 것: 적·아군 둘 다 고를 수 있는 스킬 방식 새로 (지금은 없음) · 자동 전투가 언제 아군에게 쓸지 (예: 아군 평균 체력 60% 이하)

### 아스트라이아 표식 개편
- 별자리 표식: 공격력 140% + 표식 1개 (최대 3개, 3라운드) · **이미 표식이 있는 적에게 또 쓰면 십자(앞뒤·양옆) 1칸에도 표식 1개씩**
- 별똥별: **표식이 있는 모든 적**에게 표식 하나마다 공격력 60% (표식은 안 없어짐)
- 별의 공명: 표식 붙은 적이 **지속 피해**를 받으면 표식 피해(표식 하나마다 아스트라이아 공격력 20%)가 같이 들어감 (표식은 안 없어짐)
- 지속 피해 = 화상 · 독 + 스칼렛 시한폭탄 · 금오 발화
- 지금 「터뜨리는 공격이 표식을 다 써서 +40%」는 없어짐
