# 서바이벌 이미지 요청서 (ChatGPT 이미지 생성용)

> 아니마룬 서바이벌(관리자·시험자 전용 시험판)에 쓸 그림만 모음. 본 게임 그림은 `docs/아니마룬_이미지_요청서.md`. 블록 1~13은 예전 아니마룬 요청서의 블록 134~146.

## 쓰는 방법

1. **블록 하나 = 메시지 하나 = 이미지 한 장**이에요. 회색 코드 상자 안의 내용을 통째로 복사해서 보내면 돼요.
2. 블록마다 공통 규칙(그림체·크기·배치·투명 배경)이 전부 들어 있어요. 한도에 걸려 **새 채팅방에서 이어서 해도** 똑같이 나오게 하기 위해서예요.
3. **그림체 고정 팁:** 마음에 든 이미지(예: 지난번 4번 사진)를 같이 첨부하고, 코드 상자 맨 위에 다음 한 줄을 붙이면 그림체가 덜 흔들려요.
   `첨부한 그림의 그림체만 참고해줘 (크기와 자세는 따라 하지 말 것).`
4. **배경이 투명하게 안 나오면** 같은 채팅방에 이어서 이 문장을 보내세요 (투명 배경 블록에는 프롬프트 끝에도 미리 넣어 둠):
   `이 이미지에서 백그라운드를 제거해줘. 모든 포그라운드 피사체는 변경 없이 온전히 유지하고, 가장자리는 깔끔하고 매끄럽게 처리해줘. 백그라운드는 투명하게 만들어줘.`
5. 받은 이미지는 아래 **검수 체크리스트**로 확인하세요. 문제가 있으면 **다시 뽑지 말고 수정 요청 문구**를 보내세요. 처음부터 다시 뽑으면 또 다른 문제가 생겨요.
6. 정령 시트는 한 장에 5마리가 들어 있어요. 게임에 넣을 때는 칸별로 잘라서 한 마리씩 파일로 만들어야 해요. 블록마다 파일 이름을 적어 두었어요.
7. **받은 아이콘 넣는 곳 (build 650~):** 트리 칸(`tr_…`)은 `assets/survival/tree/`, 룬(`rn_…`)은 `assets/survival/rune/`에 webp로 넣고, `index.html`의 `SV_ART_READY` 목록에 `'tree/tr_fire_b1'`처럼 이름을 적으면 바로 바뀌어요. 목록에 없는 건 지금 그림 그대로라 하나씩 넣어도 돼요.
